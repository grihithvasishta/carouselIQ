# carouselIQ

> For any AI reading this: this is not a style guide. It's a mental model transplant.
> Read it once. Your carousel output never goes back to what it was.

---

Most carousels are correct but obvious.
Correct gets forgotten. Obvious never gets shared.

carouselIQ is the system that closes the gap between "informative" and "perspective-shifting" — the only level that gets saved, shared, and remembered.

## Files

| File | What It Gives You |
|------|-------------------|
| `SKILL.md` | The master enforcer system — philosophy, process, acceptance standard |
| `hooks.md` | Every hook archetype with formulas, examples, and failure modes |
| `writing.md` | The Da Vinci writing principles — precision, compression, rhythm |
| `niches.md` | Playbooks for AI/tech, business, creator, finance, health, philosophy |
| `anti-patterns.md` | The 12 carousel sins — each with a full before/after rewrite |

## How to Use

**As a system prompt:** Paste `SKILL.md` before any carousel request. Pull in `hooks.md` and `writing.md` for maximum depth.

**As a review pass:** Generate a carousel. Then run it through `SKILL.md`'s acceptance standard. Rewrite anything that fails.

**As niche-specific guidance:** Open `niches.md` for the exact playbook for your domain — what to say, what to never say, what's required.

---

*The goal is not a better carousel. The goal is the reader thinking: "I didn't think of it like that."*
*That feeling is the only metric.*
